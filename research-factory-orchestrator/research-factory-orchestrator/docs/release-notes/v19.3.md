# RFO v19.3 — artifact-only compute, gateway-side delivery

## Summary

- **Synchronous `execute`** path: `python3 -S scripts/interface_runtime_adapter.py execute --runs-root … --task "…"` performs full render + `research-package.zip` in one process (no queue hop for this entrypoint).
- **Artifacts**: `final-answer.md`, `result-manifest.json` (JSON Schema `schemas/skill-result.schema.json`), `marker.json`, stdout line `__OPENCLAW_SKILL_RESULT__=<json>`.
- **Gateway** (OpenClaw): native `/research_factory_orchestrator` runs execute, validates manifest, delivers to Telegram, **suppresses** default LLM reply; audit log records outcomes.
- **Validators**: Telegram-specific provider files and smokes are no longer required for `validate_skill` / default `validate_release` gates; use `validate_artifact_release` for artifact contract checks.
