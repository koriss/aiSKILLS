# Release notes — v19.2.0 (Runtime Truth Restoration)

## Summary

v19.2.0 closes the **runtime ↔ validator** gap: artifacts emitted during `cmd_run`
match what V1–V6 gates consume, work units execute with evidence, collection/coverage
flags are truthful, and Telegram delivery can be proven with a **mock Bot API** trace.

  are first-class (`runtime/util.py`, `runtime/compatibility-matrix.json`).

  `sendMessage` when `TELEGRAM_API_BASE` is set; operator tools under
  `tools/agent_telegram/` (ADR-014).

  `_smoke_telegram_real_send`, and keeps v19.2 integration smokes + advisory suite.
- **Honesty harness** — `scripts/verify_openclaw_run.py` for loop testing under
  unreliable LLM narration (ADR-015).
